# Начало работы — CommunicationBot

**Что это:** тестовый Telegram-бот магазина. Он отвечает по учебному каталогу, помогает выбрать товар и размер, регистрирует обращение и уведомляет ответственного. Это **прототип оформления заявок**, а не интернет-магазин с оплатой.

## 1. Что есть в каталоге

| Код | Товар | Цена | Размеры в наличии |
|---|---|---:|---|
| T01 | Чёрная футболка | 2 490 ₽ | S, M, L |
| T02 | Серое худи | 5 990 ₽ | M, L |
| T03 | Синие джинсы | 6 490 ₽ | Нет в наличии |

Других сведений о товарах, доставке, оплате и сроках нет. Бот не должен их придумывать.

## 2. Как запустить

Нужны Windows 11, Python 3.11+ и доступ к Telegram. При установке Python включите
добавление в PATH. Скачайте репозиторий или клонируйте его через Git:

```powershell
git clone https://github.com/nonlh/CommunicationBot.git
cd CommunicationBot
python --version
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-store.txt
.\.venv\Scripts\python.exe -m pip check
Copy-Item .env.example .env
```

Команды выполняются в PowerShell или терминале Cursor. Если скачан ZIP, откройте
терминал в распакованной папке и начните с `python --version`. Активация окружения
не требуется. Копирование `.env` нужно только при первой установке.

Откройте `.env` в редакторе и заполните **только локально**:

- `TELEGRAM_BOT_TOKEN` — токен собственного бота, полученный у @BotFather.
- `TELEGRAM_ADMIN_ID` — числовой ID своего Telegram-аккаунта, не ник и не ID группы.
  Если ID неизвестен, его можно узнать у [Telegram-бота @userinfobot](https://t.me/userinfobot) командой `/start`.
- Оставьте `CATALOG_PATH=catalog/mvp_catalog.csv` и `SQLITE_PATH=data/store.sqlite3`.
- Для уведомлений администратору оставьте `NOTIFICATION_BACKEND=telegram`.
- `STORE_TEST_MODE=0`, `NOTIFICATION_FAIL_FIRST=0` — обычный запуск без имитации ошибок.

Не публикуйте `.env`: он исключён из Git. Не добавляйте в него другие параметры
и не пишите комментарии после значений в той же строке.

**Запуск:** дважды нажмите `START_BOT.bat` в корне проекта. Дождитесь сообщения
«Бот успешно запущен». Окно можно закрыть: бот продолжит работать. Повторный
запуск сообщает, если бот уже работает. Ошибка остаётся в окне для чтения.

**Остановка:** дважды нажмите `STOP_BOT.bat`. Для перезапуска остановите бота,
затем снова нажмите `START_BOT.bat`. В терминале Cursor можно запускать те же
файлы: `.\START_BOT.bat` и `.\STOP_BOT.bat`.

В Telegram откройте собственного бота по имени, выбранному в @BotFather,
и отправьте `/start`. Учебный демонстрационный бот —
[@cust_communication_bot](https://t.me/cust_communication_bot); после настройки
собственного токена запущен именно ваш бот. Администратор также должен отправить
своему боту `/start`, иначе Telegram не разрешит присылать ему уведомления.

## 3. Как пользоваться покупателю

- `/start` — начать новое обращение.
- `/catalog` — посмотреть товары и доступные размеры.
- Выберите товар, нажмите «Оформить заявку», выберите доступный размер, оставьте **вымышленные** имя и контакт для демонстрации (например, `demo@example.invalid`), проверьте данные и нажмите «Подтвердить». До подтверждения заявка не создаётся.
- Если товара или размера нет, бот сообщает об этом. Если вопрос выходит за пределы каталога (например, о доставке), можно оставить вопрос ответственному.
- `/back` — предыдущий шаг; `/cancel` — отмена текущего оформления.

## 4. Как пользоваться администратору

Команды доступны только Telegram-аккаунту с указанным в настройках `TELEGRAM_ADMIN_ID`.

| Что сделать | Команда |
|---|---|
| Открыть меню администратора | `/admin` |
| Посмотреть список заявок | `/admin list` |
| Открыть конкретную заявку | `/admin view 3` (замените `3` на номер) |
| Посмотреть сводку: всего, статусы, товары | `/admin stats` |
| Найти уведомления, требующие повтора | `/admin pending` |
| Повторить уведомление по заявке | `/admin retry 3` |
| Отметить заявку обработанной | `/admin status 3 2` |

Номер заявки — **общий внутренний идентификатор магазина**, покупателю он не нужен. Уведомление можно отправлять повторно, не создавая новую заявку.

Статус можно изменить кнопкой в карточке `/admin view НОМЕР` либо командой
`/admin status НОМЕР КОД`: `0` — «Новая», `1` — «Нужен ответ человека»,
`2` — «Обработана». После изменения `/admin stats` показывает актуальные данные.
Успешно отправленное уведомление повторная команда не дублирует. Неудачные
уведомления повторяются вручную; автоматического фонового повтора нет.

## 5. Как изменить каталог

1. Откройте `catalog/mvp_catalog.csv` в редакторе CSV.
2. Исправьте значения существующих товаров или добавьте строку **в том же формате**, не переименовывая заголовки и не дублируя ID.
3. В колонке `sizes_in_stock` перечисляйте доступные размеры через `|` (например, `S|M|L`). Пустая ячейка означает **подтверждённое отсутствие размеров в наличии**.
4. Сохраните CSV и отправьте боту `/admin_reload` с аккаунта администратора. Если новый файл некорректен, бот должен оставить предыдущий рабочий каталог.

Загрузка каталога не равна редактированию прямо в Telegram: встроенного редактора товаров в текущем прототипе нет.

## 6. Где находятся данные и что делать при проблеме

- Каталог: `catalog/mvp_catalog.csv`.
- Заявки и состояние диалогов: `data/store.sqlite3` (не удалять при перезапуске).
- Если бот не отвечает, проверьте, запущен ли он. Не запускайте второй экземпляр поверх первого.
- Если ответ о товаре неверен, проверьте каталог. Если сообщение распознано неверно — зафиксируйте **текст запроса и ответ бота**; исправлять алгоритм вручную не нужно.
- Если не пришло уведомление, откройте `/admin pending` и воспользуйтесь `/admin retry НОМЕР`.

**Ограничения:** свободный текст распознаётся по правилам и приблизительному совпадению (RapidFuzz), поэтому иногда требуется уточнение; складские остатки не резервируются; оплата и доставка не реализованы. Для проверки используйте только вымышленные контакты.
